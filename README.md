Task 2: Web Automation Testing

Tools Used:

Java
Selenium WebDriver
Page Object Model (POM) Framework
TestNG
Extent Reports
TestNG Listeners
Execution Steps
Step 1:

Import the "Sauce" project as a Maven Project into Eclipse.

Step 2:

Navigate to the sauce.xml file within the project.

Right-click on sauce.xml → Run As → TestNG Suite.

Step 3:

Upon execution, the automation suite will run, and Extent Reports will be generated automatically.

Notes
The application under test is not fully stable.
CAPTCHA verification cannot be automated using Selenium and must be completed manually during execution.
Sufficient wait mechanisms have been implemented to accommodate page loading and application response times.
During account creation, the application may occasionally display errors due to website instability rather than automation script issues.
Despite these limitations, the automation suite covers the maximum possible test scenarios and critical functionalities required for the task.
